# Subaccounts

Discover owned subaccounts for trading and account selection

## List subaccounts

> Lists the authenticated master account's pending and active subaccounts, including current equity, available balance, PnL, and margin-used percentage. Use an active account\_id from this response as sub\_account\_id on supported trading and read endpoints.

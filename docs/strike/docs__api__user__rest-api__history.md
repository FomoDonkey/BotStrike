# History

Order, fill, funding, and transaction history

## Get order history

> Returns persisted order history for the resolved account, newest first. Use fromOrderID for backward cursor pagination. Public account selectors do not require authentication; sub\_account\_id and the no-selector caller context do. Selector precedence is account\_id, vault\_id, blockchain address, then authenticated caller/subaccount.

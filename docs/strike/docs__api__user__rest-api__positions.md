# Positions

Open and closed position queries

## Get open positions

> Returns active positions for the resolved account, including derived PnL, maintenance margin, bankruptcy price, and liquidation price. Public account selectors do not require authentication; sub\_account\_id and the no-selector caller context do. Selector precedence is account\_id, vault\_id, blockchain address, then authenticated caller/subaccount.

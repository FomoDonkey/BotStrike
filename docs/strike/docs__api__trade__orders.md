## Create new order

> Create a new order. Supports the following order types:\
> \
> \| Type | Description |\
> \|------|-------------|\
> \| \`limit\` | Limit order at specified price |\
> \| \`market\` | Market order at best available price |\
> \| \`stop\` | Stop market order triggered at stop\_price |\
> \| \`stop\_limit\` | Stop limit order triggered at stop\_price |\
> \| \`take\_profit\` | Take profit market order |\
> \| \`take\_profit\_limit\` | Take profit limit order |\
> \| \`trailing\_stop\_market\` | Trailing stop market order that tracks price movement |<br>

## Replace batch orders

> Replace multiple orders in a single atomic engine command. Each replacement entry may include a cancel leg, a create leg, or both. All entries must target the same symbol. Cancels execute first, then creates run sequentially against post-cancel state. If a create fails at runtime (other than conditional trigger-immediate), remaining creates are halted.<br>

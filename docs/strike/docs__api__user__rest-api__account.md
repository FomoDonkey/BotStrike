# Account

Account info, balances, and portfolio

## Get account info

> Returns balances, margin totals, profile data, symbol settings, and active subaccount metadata. A master account response includes its active sub\_accounts. Selecting sub\_account\_id returns that owned subaccount and includes parent\_account\_id, parent\_blockchain\_address, and its active siblings. Public account selectors do not require authentication; sub\_account\_id and the no-selector caller context do. Selector precedence is account\_id, vault\_id, blockchain address, then authenticated caller/subaccount.
